Centinela-AI — Manual de Desarrollador

Guía de arquitectura, integración API y desarrollo de motores para Centinela Omni-XDR.

1. Arquitectura General y Módulos Core

Centinela AI se compone de los siguientes módulos principales en Python (FastAPI + Asyncio):

  • main.py: Endpoints REST FastAPI, WebSockets de telemetría y coordinación de tareas.
  • centinela.py: Bucle principal de correlación de vulnerabilidades con IA y enriquecimiento de inteligencia de amenazas.
  • core/itdr_engine.py: Motor de Detección & Respuesta ante Amenazas de Identidad (Authentik IdP).
  • core/soar_engine.py: Motor SOAR de Respuesta Autónoma y políticas escalonadas.
  • auditors/: Motores de auditoría nativos (SAST, DAST, SCA, CIS Benchmarks, Secretos, CMMI v3.0, WCAG 2.1).

2. Integración Webhook Shift-Left con GitLab

Configuración del Webhook para revisión de Merge Requests en tiempo real:

URL: https://centinela.casmart.internal/api/gitlab/mr-webhook
Trigger: Merge Request Events
Secret Token: <GITLAB_WEBHOOK_TOKEN>

3. Endpoints Clave de la API REST

  • GET /api/manual — Sirve el Manual Técnico Oficial HTML.
  • GET /api/manual/user — Sirve este Manual de Usuario HTML.
  • GET /api/manual/developer — Sirve este Manual de Desarrollador HTML.
  • GET /api/itdr/telemetry/recent — Obtiene eventos de telemetría ITDR Authentik.
  • POST /api/itdr/authentik/webhook — Ingesta de eventos en tiempo real desde Authentik.
  • GET /api/reports/executive — Genera y descarga el reporte en PDF con WeasyPrint.
